# 자전거 2D 관절 애니메이션 비교 테스트

운영 페이지의 기존 9프레임은 변경하지 않는다. 이 폴더는 별도 비교용 미리보기다.

- `index.html`: 기존 스프라이트와 관절 애니메이션을 나란히 보여주는 비교 화면.
- `rig.js`: 원형 페달 궤도에 맞춘 두 관절 다리 계산 및 SVG 렌더링.
- `reference.png`: 기존 `story-02-sprite.png`에서 추출한 첫 프레임(432×352).
- `old-sprite.webp`: 비교 재생용 기존 9프레임 시트의 사본.

새로운 이미지 생성은 사용하지 않았다. 기존 첫 프레임의 얼굴·상체·가방은 SVG 클리핑으로 재사용하고,
다리·신발·자전거 프레임·바퀴는 SVG로 구성했다. 원본 이미지 파일은 변경하지 않는다.
다리 길이는 고정하고, 페달과 발의 접점을 기준으로 무릎 위치를 계산한다.
양쪽 페달은 180도 차이를 유지한다. 기본 한 바퀴 시간은 기존 스프라이트와 같은 2.88초다.
바퀴는 페달 한 바퀴에 두 바퀴 돌며, 브라우저 화면 갱신 속도로 연속 재생한다.

일시정지, 속도 변경, 진행 위치 조절, 관절 표시를 지원한다.
`prefers-reduced-motion`이면 정지 상태로 시작하며, 사용자가 재생 버튼으로 시작할 수 있다.
숨겨진 탭에서는 프레임 요청을 중지한다.

720개 페달 각도에서 다리 길이·반대편 페달·발 도달 가능 범위·반복 연결을 검증했다.
모바일 320/375/430px, 컨트롤과 동작 줄이기 설정도 Chromium으로 확인했다.
손으로 그린 질감을 완성한 최종 삽화가 아니라, 동작의 일관성을 비교하는 시안이다.

로컬 확인:

```sh
python3 -m http.server 3014 --bind 127.0.0.1 --directory design/story-bike-rig
```

공유용 사본은 `data/media/previews/bicycle-rig-v1/`에 저장한다.
접속 경로는 `/media/previews/bicycle-rig-v1/index.html`이며, 메인 페이지 코드와 배포 이미지는 변경하지 않는다.
