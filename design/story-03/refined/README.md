# 세 번째 애니메이션 — 시선과 구름 흐름 정리

https://married.3chan.kr/ 의 세 번째 이야기, 비행기 좌석 장면을 소폭 수정했습니다.

## 수정 내용

- 원본 2·3번 프레임의 순서를 교환했습니다. 창밖에서 정면으로 돌아보다 다시 창밖으로 되돌아가는 동작을 줄였습니다.
- 새 8번의 여성 머리와 목 연결 부분을 국소 교정했습니다. 남자 쪽을 보다가 창밖으로 돌아설 때 정면에 가까운 중간 시선을 거칩니다. 얼굴은 원본의 정면 프레임을 참고했습니다.
- 구름을 원본에서 분리하고, 창 안의 하늘을 복원해 구름이 오른쪽에서 왼쪽으로 흐르게 배치했습니다. 반복 경계에서도 같은 방향으로 이어집니다.
- 남자와 여성의 손, 의상, 좌석, 창틀 및 원래의 미세한 그림 차이는 각 원본 프레임대로 유지했습니다. 교정 영역 바깥의 픽셀은 해당 원본 프레임과 동일합니다.

## 파일과 사양

- `story-03-sprite-3x3.png`: PNG 스프라이트, 1296×1056px.
- `story-03-sprite-3x3.webp`: 동일한 배열의 무손실 WebP 스프라이트. 이 파일 자체는 정지 이미지입니다.
- `story-03-animation.webp`: 이미지 하나로 재생되는 애니메이션.
- `story-03-preview.gif`: 반복 재생 미리보기.
- `story-03-sheet-preview.png`: 전체 9프레임 확인용 이미지.
- `frames/`: 개별 PNG 9장, 각 432×352px.
- `story-03.css`, `index.html`: 서버에서 바로 재생하는 예제.
- `PROMPTS.md`: 내장 ImageGen 편집에 사용한 실제 프롬프트 두 개.

배열은 3열×3행, 왼쪽 위부터 가로 방향으로 1~9번입니다. 프레임당 320ms, 전체 2.88초, 무한 반복입니다. 원본에 그려진 밝은 배경을 포함합니다.

## 서버 적용

기존 세 번째 스프라이트의 PNG와 WebP 참조를 각각 새 `story-03-sprite-3x3.png`, `story-03-sprite-3x3.webp`로 교체하세요. 사이트가 `<picture>`로 WebP를 우선 사용하므로 두 경로를 함께 바꾸어야 합니다. 기존 3×3 재생 코드와 2.88초 속도를 유지하면 됩니다.

새 페이지에서는 CSS와 PNG를 같은 폴더에 올린 뒤 아래 경로를 실제 위치로 바꾸세요.

```html
<link rel="stylesheet" href="/assets/story-03/story-03.css">
<div class="story-03-animation" role="img" aria-label="비행기에서 서로 바라보는 두 사람"></div>
```

이미지 파일 하나로 재생하려면 다음처럼 사용합니다.

```html
<img src="/assets/story-03/story-03-animation.webp"
     width="432" height="352" alt="비행기에서 서로 바라보는 두 사람"
     style="max-width:100%;height:auto">
```

실제 서버에는 업로드하지 않았습니다. 이 폴더는 업로드 가능한 파일 묶음입니다.
