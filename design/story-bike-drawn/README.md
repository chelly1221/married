# 직접 작성한 Canvas 드로잉 · 자전거 9프레임

이미지 생성 도구, 생성된 이미지의 부분 합성, 외부 이미지, 자동 트레이싱을 사용하지 않았다.
`draw.js`에 인물·머리카락·옷·신발·자전거·가방의 윤곽선과 채색, 연필 질감 스트로크를 직접 작성했다.
손으로 펜을 조작한 그림은 아니며, Canvas 2D 드로잉 코드로 그린 별도 시안이다.
기존 사이트의 종이색·적갈색·갈색 계열을 참고했으나 기존 삽화를 복제하지 않았다.

- `index.html`: 9프레임 재생, 한 장씩 보기, 속도 조절, 전체 프레임 썸네일.
- `draw.js`: 모든 드로잉의 원본. 외부 의존성 없이 브라우저 Canvas에서 실행된다.
- `frames/01.png` ~ `09.png`: 개별 프레임, 864×704.
- `bicycle-sprite.png`, `bicycle-sprite.webp`: 1296×1056, 3×3 시트(프레임 432×352).

상체와 자전거 구조는 고정하고 40도 간격의 9개 페달 위치에 맞춰 다리를 그렸다.
프레임당 320ms, 2.88초 반복. 움직임 줄이기 설정에서는 정지 상태로 시작한다.
숨겨진 탭에서는 타이머를 멈춘다.

9개 프레임이 서로 다름을 확인했고 모바일 320/375/430px, 재생·한 장 넘기기·동작 줄이기를 검증했다.
메인 React 클라이언트나 서버 코드는 수정하지 않으며, 운영 페이지의 기존 삽화는 그대로다.

미리보기 사본: `data/media/previews/bicycle-drawn-v1/`
주소: `/media/previews/bicycle-drawn-v1/index.html`
